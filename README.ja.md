# 珈琲のおとも

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

『活俠傳』（Legend of Mortal）用の BepInEx 6 プラグインです。名前の「咖啡伴侣」（コーヒーのおとも）は、プレイヤーが瑞杏につけたあだ名「咖啡」（コーヒー）から来ています。瑞杏の中国語読みが中国のコーヒーチェーン「瑞幸（Luckin Coffee）」と同じだからです。最新版のゲームに対応し、AIお供、ストーリーの全体像、分岐の選択、数値エディタ、セーブの改良などを追加します。

[日本語化MOD](https://dlaqe2334.github.io/LOM-JPMOD/)を導入している場合、このMODのウィンドウやメッセージは自動的に日本語で表示されます（設定タブ上部の「表示言語」でも切り替え可能）。現在はよく使う画面の文字だけを翻訳しており、それ以外は中国語のままです。翻訳は正確でない場合があります。おかしな訳を見つけたら [Issues](https://github.com/kevinnie2003/LOMAssistant/issues) で教えてください。以下のスクリーンショットは中国語版です。

## 導入

ZIP には BepInEx が同梱されています。

**インストーラー（おすすめ）**：解凍して `咖啡伴侣安装器 Installer.exe` を実行し、「インストール／更新」をクリックします。ゲームフォルダを自動で探して最新版をダウンロードし（GitHub に繋がらない場合は同梱版を導入）、競合する古いMODは `BepInEx\DisabledMods` に移動します（削除はしません）。更新するときはもう一度実行するだけです。インストーラーは Windows の表示言語に合わせて表示されます。

<img src="media/installer.ja.webp" width="640" alt="インストーラー：ゲームフォルダ、インストール済みと予定のバージョン、更新内容、インストール／更新、診断の書き出し、アンインストール">

**手動**：Steam で『活侠傳』を右クリック → 管理 → ローカルファイルを閲覧し、ZIP の中身をすべてゲームフォルダに上書きで展開します。先に `BepInEx\plugins` から同種の古いMOD（骰子大师、多功能 Mod、赵活系统）を削除してください。

**アンインストール**：インストーラーの「アンインストール」をクリックします。セーブデータには影響しません。

## ホットキー

| キー | 機能 |
|---|---|
| Tab | 咖啡伴侣ウィンドウ（いま、ルート図、ストーリー図、分岐セーブ、クイックセーブ、収集状況、数値、AIお供、設定） |
| F3 | AIお供タブ |
| F8 | 設定。セーブ画面では選択中のセーブにメモを書く |
| F9 | 数値タブ |
| F10 | メモ帳 |
| F5 / F7 / F6 | クイックセーブ：保存／最新をロード／一覧 |
| F2 | 既読会話を早送り。未読の会話で止まる |
| F4 | 判定前に戻す |
| 右クリック | UI を隠して CG を見る |
| パッド L3 | 咖啡伴侣ウィンドウを開閉 |
| ESC | ゲームのメニューに「見送り」「即勝利」「診断を書き出す」を追加 |

キーは設定タブの「ホットキー」で変更・解除できます。

## 機能

### AIお供（F3）

自分の API Key で大規模言語モデルにつなぎ、ストーリーや攻略を質問したり、ヒロインや大師兄とおしゃべりしたりできます。DeepSeek、Kimi、通義千問、智譜 GLM、SiliconFlow、OpenRouter、OpenAI、Claude、Gemini、ローカルの Ollama、そのほか OpenAI 互換の API に対応しています。

- **攻略アシスタント**：ゲーム内のストーリーデータを調べてから答えます。任務と発生条件、台本の分岐と会話、ルートごとの好感度・数値の合計、エンディングと死亡、縁結びルート、人物誌、場所イベント、決闘の条件、それに今の進行状況と画面の選択肢。
- **ヒロインと大師兄**：縁結びできる九人のヒロインと大師兄の唐布衣が本人の口調で話し、立ち絵の表情も話に合わせて変わり、呼び方はストーリーに合わせて変わります。知っているのはプレイヤーが読んだストーリーだけです。攻略を聞くと返事のあとに攻略ヒントが別に付きます。おしゃべりだけにもできます。
- **ネタバレの程度**：何でも答える／今と通った所だけ／方向のヒントだけ。
- **数値と設定の変更**：数値、好感度、想い人、フラグ、この Mod の設定を変えるときは、AI がまずカードを出し、確定を押すまで変わりません。
- **会話**：会話は相手ごとにローカルに保存され、新規・切り替え・削除のほか、デスクトップへの書き出しもできます。返事は書かれたそばから表示されます。
- **じっくりモード**：より強いモデルに切り替え、答える前に資料を確かめます。より正確ですが、料金が高く時間もかかります。
- **料金とプライバシー**：料金はプロバイダーの価格どおりで、この Mod は無料です。Key と会話は選んだプロバイダーにだけ送られ、診断の書き出しでは Key は伏せられます。

### ストーリー回顧（Tab）

- **いま**：今の場面の選択肢・ダイスの結果、分岐条件、その後の会話を読んだかどうか。現在地のランダムイベントと確率、未読のもの（次に起こすものを選べます）。進行中のメイン・サブクエストの発生場所と、足りない条件。

  <img src="media/story-now.webp" width="640" alt="いま：この場面の選択肢を選択ごとに分け、数値の増加は緑、減少は赤。進行中のクエスト">

- **ルート図**：メインストーリー全体を暦に沿って一本の線に並べ、分岐は上下に分かれて合流するとメインに戻ります。分かれる線には発生条件を表示し、サブクエストは下に表示。複数のルートが並ぶところ（三つの留学ルート、あなたの決断など）はそれぞれ別の線に分け、交差させません。チェックは今回のプレイで通ったもの、赤い「今」は今いるメインの駅、次の駅は金色の輪で囲み、「現在地へ」でここに戻れます。駅をクリックすると、次にどこへ進むか（いつ・どこで・条件）、発生条件、駅の中の分岐、この段階の選択肢（既定は折りたたみ、開くと選択肢ごとの条件と結果）が分かります。サブクエストは次の段階と、終えるとどのメインの駅に戻るかを表示します。任務名・場所・台詞・フラグで検索でき（ピンインの頭文字でも検索可）、フラグはどのストーリーで変更・判定されるかを一覧します。

  <img src="media/story-route.webp" width="640" alt="ルート図：メインストーリーを暦の駅として並べ、サブクエストは下に">

- **縁結びルート**：ルート図で縁を結べる人物を選ぶと、関係するストーリーだけが明るく残り、各段階の達成状況と入手場所を表示します。

- **ストーリー図**：任務ひとつを流れ図にします。場面ごとの枠に行き先（選択肢・サイコロ・条件）を一行ずつ並べ、その行から行き先の場面へ線を引きます。選んでもその場面に残る選択肢も表示。行にマウスを乗せると、条件と変化の全文が見られます。崆峒・青城での日常や江陵など、場所のストーリーにもストーリー図があります（閲覧のみ）。

  <img src="media/story-flow.webp" width="640" alt="ストーリー図：場面のあいだの選択肢、条件、行き先">

- **分岐セーブ**：ストーリーのセーブ地点と各旬の始めのオートセーブに合わせて進行を保存し、「ここからやり直す」で戻って別のルートを試せます。セーブごとに別管理で、セーブ枠は使わず、Steam クラウドで同期されます。

  <img src="media/story-nodes.webp" width="640" alt="分岐セーブ：記録した場面を日付順に並べ、やり直し・削除">

- **ストーリージャンプ**：ルート図かストーリー図で場面を選び「ここへジャンプ」を押すと、その場面から直接遊べます。まだ着いていない場面でも大丈夫なので、ストーリーの補完や別ルートでのエンディング集めに使えます。ジャンプ前に、この先のストーリーに関わる途中の選択が一覧になり、選んだとおりに途中の進行を補います。ついでにヒロインの一人と縁を結ぶこともできます。行き先の場面の中で条件によって分かれるところは、未読の会話がある方を既定で選び、ジャンプ後は値を変えずにそのままその方へ進みます。「分岐を選んだら値を合わせる」をオンにすると先にその条件を補い、補えないときはそのままその方へ進みます。ジャンプ前にクイックセーブが自動で一つ残るので、いつでも戻れます。途中のストーリーは実際には遊んでいないため、ときどき話が合わないことがあり、通常のプレイにはおすすめしません。

  <img src="media/story-jump.webp" width="640" alt="ストーリージャンプ：ジャンプ前に変わる任務・日付・補う変化を表示し、ついでに縁を結んだり、途中の分かれ道を一つずつ選んだりできる">

- **収集状況**：全周回の記録。ストーリーは各任務の会話をどれだけ読んだかで数え、エンディング・死亡・実績・エンディング CG は図鑑番号と達成状況を表示。未達成のものは場所と到達方法を表示します。各項目の下にそこへ至る任務が並び、クリックするとその任務のストーリー図が開きます。「エンディング CG」ページの「エンディングロールを見る」で、ストーリーシーンの中でクリア時のエンディングロールをもう一度流せます（Esc で終了）。

  <img src="media/story-endings.webp" width="640" alt="収集状況：ストーリー・エンディング・死亡・実績・エンディング CG。達成・未達成で絞り込み">

### ストーリー補助

- **ダイスを選ぶ**：ダイス判定でルートをクリックすると、その結果になります。
- **選択肢の結果**：会話の選択肢やダイスのルートに、選ぶと何が変わるかを表示。ロックされた選択肢には本当の解放条件を表示し、「ワンクリック解除」で条件を満たせます。「条件未達の選択肢を強制選択」をオンにすると（プリセットでは「すべてオン」だけがオン）、条件を満たさないと出ない選択肢も赤字の「条件未達」付きで表示され、マウスを乗せると条件が見られます。条件を満たせないロックされた選択肢には「強制解除」が付き、フラグを変えずにそのまま解除できます。設定の「選択肢の結果」で、常に表示／マウスを乗せたときだけ表示（見なければネタバレなし）／表示しない、を選べます。

  <img src="media/option-hint.webp" width="640" alt="選択肢の後ろに結果と解放条件を表示">

- **既読表示**：会話の選択肢やダイスのルートの後ろに、その先のセリフが既読かどうかを表示します（未読・一部既読・既読）。設定の「選択肢・ダイスの既読表示」で切り替え、「上級」「すべてオン」プリセットでオンになります。

- **ランダムイベントを選ぶ**：仕事や散策などで起こりうるイベントの確率と変化（条件で分かれる変化は条件つき）を見て、起こすイベントを選ぶか、本来の確率で抽選します。まだ見ていないイベントには「未読」と表示されます。乱数で決まる分岐も道を選べます。各イベント・各道に「必ず」「出さない」を設定でき、記憶されて、この機能がオフでも効きます。設定で「条件未達のイベントを強制発生」をオンにすると（プリセットでは「すべてオン」だけがオン）、発生条件を満たしていないイベントも下に畳まれ、必要な条件が書いてあり、押すと条件を無視してそのまま起こせます。フラグは変えません。

  <img src="media/event-picker.webp" width="480" alt="ランダムイベントを選ぶ：発生しうるイベント、確率、変化">

- **判定前に分岐を選ぶ**：条件で分かれるストーリーの判定で、別の分岐に未読の会話があるか別の話につながるときに先に止まり、分岐ごとの条件・現在の値・会話を読んだかを一覧にし、選んだ分岐へ進みます。既定では値は変えず、今回の判定だけその分岐へ進みます。「分岐を選んだら値を合わせる」をオンにすると、その分岐になるよう能力値・好感度・フラグをちょうど合うだけ変え（変えた値は残ります）、変えられないときはそのままその分岐へ進みます。進める分岐が一つしかない判定や、ほかの分岐に新しい内容がない判定では止まりません。「既読の分岐でも止まる」をオンにすると、ほかの分岐に会話があれば既読でも止まります。表示されると早送りを止めます。

- **マップの建物イベント表示**：育成マップで建物にマウスを乗せると、そこのメイン・サブクエスト（発生できるか、条件）とランダムイベントの確率を表示。いま発生できる未プレイのクエストがある建物は光り続けます。設定の「マップ表示は発生できるものだけ」をオンにすると、今入ると発生するものだけを表示し、残りは件数だけ書きます。建物に入った後、薪運びや修練などの選択肢にマウスを乗せると、それを選んだときに抽かれるランダムイベント、確率、未読のものを表示します。外出リストの移動や行商も同じです。
- **期限付きストーリーの通知**：条件は満たしているがまだ起きていないストーリーの発生期間が残り 3 旬以内になると、育成マップの左上に残り何旬か、いつまでか、どこへ行けば起きるかを表示します。「いま」タブの任務にも表示します。アシスト以上のプリセットでオン。
- **メモ帳**（F10）：ゲーム画面の上に浮かぶ小さなウィンドウで、「いつまでに何をする」を記録します。数値・好感度・天賦・施設・アイテム・フラグ、武学・鍛造・錬丹の層や進み具合から条件を検索して選び、目標値と期限を決めます。今の値・進み具合・残り何旬かを表示し、達成したとき、再び下回ったとき、期限が近いとき・過ぎたときにウィンドウ上部でお知らせします。ドラッグで移動、サイズ変更、折りたたみができます。
- **アイテムの用途**（任務名のネタバレの可能性あり）：持ち物と店のアイテム説明のあとに、使ったときの効果と、それを判定したり回収したりするストーリーを表示。設定は「アイテム説明に用途を表示」。
- **分岐ウィンドウ**（ネタバレ注意）：分岐判定のたびに画面左に各分岐の条件を表示。満たしていれば緑、満たしていなければ赤。

  <img src="media/branch-panel.webp" width="480" alt="分岐ウィンドウ：満たした条件は緑、満たしていない条件は赤">

- **フラグ変化の通知**（ネタバレ注意）：ストーリーがフラグを変えると画面に通知。表示秒数は変更できます。
- **バックログの判定記録**：通った判定・条件・その時の数値をバックログに記録します。
- **UI を隠して CG を見る**：ストーリー中に右クリックで背景・CG・立ち絵だけに。もう一度右クリック、左クリック、またはほかのキーで元に戻ります。

### セーブ

- **クイックセーブ**：会話・選択肢・ダイスの時や育成画面で保存でき、ゲームのスロットは使いません。F5 で保存、F7 で最新をロード、F6 で一覧（メモ、その時の会話。セーブ枠・保存日時・ゲーム内の日付ごとにまとめて表示、絞り込み、まとめて削除）。既定では上限なし、設定で上限を決められます。戦闘中は不可。
- **判定前に戻す**：判定を見たあと F4 で直前の会話に戻り、F9 で数値を調整して進むと判定し直します。

  <img src="media/anytime-save.webp" width="640" alt="クイックセーブタブ：一覧、ロード、メモ、削除">

- **新しいセーブ・ロード画面**（本来の画面に戻せます）：意中の人の顔、日付、メモが並び、詳細には意中の人の立ち絵（そのセーブで結縁済みなら照れた表情）とロード後の最初の会話を表示。手動とオートは別ページ。開くと最後に保存したセーブを選びます。ロード画面の右上でスロット順と新しい順を切り替えられます。新しい順のときは、セーブ画面のいちばん上に空きスロットを置きます。

  <img src="media/save-browser.webp" width="640" alt="新しいロード画面：左に意中の人の顔とメモ付きのセーブ一覧、右に立ち絵とロード後の会話">

- **スロットを追加**：手動セーブ 100（本来は 20）、伝奇スロット 5 ページ（本来は 1 ページ 12 枠）、オートセーブは種類ごとに旧データを 5 個保持。
- **セーブのメモ**：Steam クラウドで同期。LOM_SaveSlotExpander のメモも取り込みます。

### 育成

設定タブ（F8）の「育成」グループのスイッチ：

- ゲーム速度 1x / 2x / 3x / 5x（戦役と自動で進む会話は通常速度。設定で「戦役にも速度を適用」をオンにすると戦役も速くなる）
- 行動力：通常／消費なし／毎旬N回
  > ⚠️ 後の二つはストーリーが発生しなかったり早まったりし、重要なメインクエストが止まることもあります。こまめにセーブしてください。
- 能力値の上限突破。修練・鍛造・錬丹で回数とポイントを消費せず、鍛造・錬丹は銀両不要
- 装備開発でストーリー条件を無視：鍛冶場・錬丹房で新しい装備や薬を、解放するストーリーの前でも開発できます。等級と門派規模の条件はそのまま
- 開発項目を直接交換：鍛冶場・錬丹房の開発画面に同じ種類の別系統も表示。項目レベルと門派規模が足りていれば、既定の項目に戻らず直接交換できる
- ピンボールの合計点。四師兄が全アイテムを販売

そのほか：

- **見送り**：育成画面や留学マップの ESC メニューから。行動を 1 回消費し、イベントは起きません。
- **進行の高速化**：シーン切り替え、ロード、早送りが速くなり、数値変化後の待ちが短く、決闘のターン間の待ちもなくなります。

### 戦闘

**決闘システム刷新**：相性で勝つと追加効果がある（追撃、次のターン相手の行動を一つ封じる、奥義を外させる、重傷、反撃など）。敵味方共通のルール。敵は気力、体力、主人公が繰り返す行動に応じて行動を変える。最初の決闘で説明が表示される

<img src="media/duel-rework.webp" width="640" alt="決闘システム刷新の説明：相性は変わらず、勝つと効果が一つ増える">

設定タブ（F8）の「戦闘」グループのスイッチ：

- 決闘の敵を主人公に合わせる：決闘の開始時に主人公の 6 つの能力値の合計に合わせて敵の体力と能力値を上げる。強敵は通常の敵より明らかに強いまま
- 決闘の敵行動予測：敵の予定行動を表示。ウィンドウは移動・リサイズ可
- 決闘で無敵、敵にダメージなし。戦役で味方にダメージなし、奥義クールタイムなし
- 戦役の操作感改善：硬直後に方向キーが効かなくなる問題を修正。通常攻撃は最も近い敵へ向かい、判定範囲が広がり、気力を消費しない。平射の暗器は最も近い敵を狙い、溜め投げは外れなくなり、撃破すると奥義のクールタイムが縮み、連続撃破でさらに縮む。主人公の足元に通常攻撃の範囲を表示。主人公の奥義の範囲が広がる。ドロップの取得範囲も広がる。味方の暗器・罠・毒霧で主人公が傷つかず、戦役の結果で性情と貢献度が減らない
- 戦役の援軍選択：戦役の開始画面の奥義リストに好感度 40 以上の仲間が加わり、ストーリーが指定した仲間に限られなくなる
- 戦役の敵軍士気：通常の戦役に敵軍の士気が加わる。敵兵の死亡、主人公の撃破、連続撃破、敵の首領の撃破で士気が下がり、0 になると敵軍が潰走して味方の勝利となる。イベントのある戦役には適用されない

そのほか：

- **即勝利**：決闘・戦役の ESC メニューから。
- **スキル一覧の分割**：戦闘中、味方のスキル一覧が長いと列に分けます。

### 数値タブ（F9）

能力値、武功、門派、好感度（全員）、天賦、修練・鍛造・錬丹のポイント、施設、書籍、アイテム、フラグを 1 ページで増減・直接設定でき、名前・ID・説明・ピンインの頭文字で検索できます。

- **書籍・アイテム**：数を直接設定。お店で買ったのと同じようにクエストが進みます。武学書の名前にマウスを乗せると、各層を修得したときに上がる能力を表示し、修得済みの層にはチェックが付きます。
- **数値**は秘伝書などの加算分より下やマイナスにも設定でき、その後のストーリーでの増減やロードでも保たれます。
- **意中の人**は名前で表示。心相・四つの性格・陰陽・銀両にはそれぞれ**ロック**があり、かけるとストーリーや選択肢で変わらず、再起動やセーブを替えてもロックされたままです。
- **称号**：全称号から選ぶか、自分で書けます。
- **フラグ**：千以上を門派好感・人物・六道・ストーリーなどに分類。
- **逆引き**：フラグ・書籍・アイテムの名前をクリックすると、どのストーリーで変更・判定されるかを一覧します。好感度の人名をクリックすると、判定される場所を一覧します。どれもストーリー図へ移動できます。
- **数値プリセット**：数値タブで変更した項目を記録し、「数値プリセット」でプリセットとして保存します。別のセーブを読み込んだときや新しく始めたときに「適用」を押すと、まとめて保存した値にします。変更していない項目はそのままです。

<img src="media/stats.webp" width="640" alt="数値タブ：能力値、武功、門派、称号、好感度などをグループごとに編集">

むやみに数値やフラグを変えるとストーリーが壊れることがあります。先にセーブしてください。

### その他

- **ゲームパッド**：ウィンドウ全体をパッドで操作できます（L3 で開閉、左スティックでポインター、A でクリック、LB / RB でタブ切り替え）。ダイス、見送り、ランダムイベント選択も対応。
- **画面**：ダークモード、思源宋体か微軟雅黒、ウィンドウ・小ウィンドウ・表示ボックスの不透明度をそれぞれ調整、会話文字の拡大。
- **言語**：簡体字・繁体字・韓国語はゲームの言語に合わせ、[日本語化MOD](https://dlaqe2334.github.io/LOM-JPMOD/)を入れていれば日本語、英語パッチを入れていれば英語で表示。設定でも選べます。
- **診断を書き出す**：ESC →「環境設定」→「診断を書き出す」で、ログと設定をデスクトップにまとめます（セーブは含みません）。インストーラーにもあります。
- **競合検出**：競合する古いMODがあると設定タブの一番上に表示（同じ箇所を変えていても一緒に動くMODは表示しません）。ほかのMODと同じキーなら、このMODの方を譲ります。
- **伝奇を書き出す**：「状態 → 伝奇」から、今回のプレイの伝奇をいつでも txt に書き出せます。
- **起動を速く**：タイトルのアニメーションを速め、インストーラーで冒頭のロゴを飛ばせます。
- **ほか**：タイトル画面の人物を選べる、講経堂で汗青書・生死簿の達成条件を表示（すべて解放も可）、別ウィンドウに切り替えてもゲームを止めない設定、ウィンドウ右上で各バージョンの更新内容と新版のお知らせ。

## よくある質問

**不具合があったら？** まずインストーラーをもう一度実行して最新版にしてください。それでも直らなければ、診断を書き出して [Issues](https://github.com/kevinnie2003/LOMAssistant/issues) に状況と一緒に投稿してください。

**導入しても何も変わらない？** タスクトレイから Steam を完全に終了してから、ゲームを起動し直してください。

**ゲームのパスに日本語などが含まれている？** 英語以外の文字を含むパスでは BepInEx の読み込みに失敗します。ゲームフォルダを英数字だけのパスに移し（Steam でゲームを右クリック → プロパティ → インストール済みファイル → インストールフォルダを移動）、インストーラーをもう一度実行してください。

**選択肢の結果が出ない、ダイスが選べない？** 同種の古いMODが入っています。インストーラーなら自動で処理します。手動の場合は `BepInEx\plugins` から古いMODを削除してください。

**ほかの Mod と一緒に使える？** 使えます。機能がぶつからない Mod なら一緒に入れられます。ショートカットキーがぶつかったときは自動で譲り、設定の「ホットキー」で別のキーに割り当てられます。ほかの Mod が BepInEx を同梱している場合は、入れたあとで本 Mod のインストーラーをもう一度実行してください。

**Linux / Steam Deck？** 手動で導入し、Steam の起動オプションに `WINEDLLOVERRIDES="winhttp=n,b" %command%` を追加してください。

## 設定

設定はすべてウィンドウの設定タブ（F8）にあり、変更はすぐ保存されます。再起動が必要なものには印が付き、名前にマウスを乗せると説明が出ます。`BepInEx\config\LOMAssistant.cfg` にも保存されます。

<img src="media/settings.webp" width="640" alt="設定タブ：スイッチ・数値・ゲーム速度・ホットキーをグループごとに">

**プリセット**：設定タブの一番上で「原作どおり」「アシスト」「上級」「すべてオン」にワンクリックで切り替えられます。変わるのはストーリーの表示、育成・戦闘の補助、チート類のスイッチだけで、セーブ・高速化・画面・ホットキーはそのままです。どれか一つでも変えると「カスタム」になり、あとで戻せます。新しく入れたプレイヤーは、初めてウィンドウを開いたときに一度選びます。選ばなければ「アシスト」のままです。

| プリセット | オンになる機能 |
|---|---|
| 原作どおり | 下に挙げた機能はすべてオフ |
| アシスト | 選択肢情報・判定記録、選択肢の結果、ロック選択肢を即解放、ダイスを手動で選ぶ、マップ建物イベント、期限付きストーリーの通知、育成「見送り」ボタン、決闘の即勝利ボタン、戦役の即勝利ボタン、講経堂の解放表示、戦役の操作感改善、戦役の敵軍士気、修練無制限、鍛造・錬丹無制限、鍛造・錬丹は銀両不要 |
| 上級 | 「アシスト」のすべてに加えて：分岐判定を表示、フラグ変化を表示、ランダムイベントを選ぶ、アイテム説明に用途、選択肢・ダイスの既読表示、ストーリージャンプ、決闘の敵行動予測、戦役の援軍選択 |
| すべてオン | 「上級」のすべてに加えて：判定前に分岐を選ぶ、条件未達のイベントを強制発生、条件未達の選択肢を強制選択、四師兄が全品販売、装備開発の条件を無視、決闘で味方無敵、戦役の味方無敵、戦役で奥義クールなし、講経堂の全解放表示 |

一覧にない機能はプリセットで変わらず、設定タブで個別に切り替えられます。
